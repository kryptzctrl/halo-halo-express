# Halo-Halo Express

A browser game about serving halo-halo to a crowd of customers.

## Run in VS Code
1. Open the `halo-halo-express` folder in VS Code (File > Open Folder).
2. Install the **Live Server** extension, right-click `index.html`, then choose **Open with Live Server**.
   (You can also just double-click `index.html` to open it in a browser.)

## Files
- `index.html` : page structure (menu, stage, tray, panels)
- `css/style.css` : all styling, scene art and animations
- `js/script.js` : game logic, customers, glasses, levels, sound

No build step or dependencies are needed.
